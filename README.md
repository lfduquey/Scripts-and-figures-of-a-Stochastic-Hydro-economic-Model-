##Scripts and Figures for a Stochastic Hydro-Economic Model of Flood Warnings

This repository contains the data, scripts, and figure-generation material used in the manuscript:

A Stochastic Hydro-Economic Model for Exploring the Economic Effectiveness and Reliability of Flood Warnings

The manuscript has been submitted to Water Resources Research for consideration for publication.

Repository description

The repository was created to support transparency and reproducibility of the analyses presented in the manuscript. It includes the scripts used to conduct the stochastic simulations, perform the sensitivity analyses, and generate the figures included in the main text and supplementary material.

The study develops a stochastic hydro-economic modelling framework to evaluate the economic effectiveness and reliability of flood warnings. The framework represents the full flood warning chain, including flood and forecast generation, warning decisions, response actions, and flood damage outcomes. It compares deterministic and probabilistic warning strategies under different assumptions about forecast lead time, proactive response performance, and warning response cost.

Repository structure

The repository is organized using separate branches for each figure. Each branch contains the data and scripts required to reproduce the corresponding figure.

Current branches include:

main: General repository information and documentation.
Figure-1: Material used to generate Figure 1.
Figure-2: Material used to generate Figure 2.
Figure-3: Material used to generate Figure 3.
Figure-4: Material used to generate Figure 4.
Figure-5: Material used to generate Figure 5.
Figure-S1: Material used to generate Supplementary Figure S1.
Figure-S2: Material used to generate Supplementary Figure S2.

Users should switch to the relevant branch to access the scripts and data associated with each figure.

Data and scripts

The repository includes the input data, model parameters, and scripts required to reproduce the analyses and figures presented in the manuscript. The scripts support the implementation of the Monte Carlo flood and forecast generator, the flood warning decision component, and the response and impact component of the hydro-economic model.

The data are provided only for research transparency and reproducibility purposes. They should be interpreted in the context of the manuscript, which presents a simulation-based study using realistic parameters and functions rather than a single operational case study.

How to use this repository

To reproduce a specific figure:

Select the branch corresponding to the figure of interest.
Download or clone the branch contents.
Run the scripts following the instructions provided in that branch.
Compare the generated outputs with the corresponding figure in the manuscript.
Manuscript availability statement

All scripts used to conduct the analyses and generate the figures presented in the manuscript are publicly available in this repository.
